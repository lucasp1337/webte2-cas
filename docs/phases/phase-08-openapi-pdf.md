# Phase 08 — OpenAPI docs + queued PDF generation

**Duration**: 1 d
**Tier**: any
**Required reading**: `CLAUDE.md`, `docs/ARCHITECTURE.md` §§ 7, 11

## Goal

Auto-generated OpenAPI spec served as JSON, rendered as Swagger UI, and downloadable as a PDF that meets the brief's "5/8" page-numbering requirement. PDF generation runs as a queued job on `cli` so the browser doesn't wait for Chromium.

## Definition of Done

- [ ] `GET /api/openapi.json` returns the spec generated by Scramble
- [ ] `/api-docs` (locale-prefixed) renders Swagger UI against that spec
- [ ] `POST /api/v1/api-docs/pdf` enqueues `GenerateApiDocsPdfJob`, returns `{export_id, status: 'queued'}`
- [ ] `GET /api/v1/api-docs/pdf/{exportId}` polls status; downloads PDF when ready
- [ ] PDF includes header (title) and footer (page X / Y) on every page
- [ ] PDF rendered bilingually based on `?locale=sk|en` on the request
- [ ] `RegenerateApiDocsCacheJob` runs daily 04:00, caches the spec to Redis
- [ ] PHP image includes Chromium for Browsershot
- [ ] Spec covers every route added in Phases 03/05/06/07/09 with example payloads

## Prerequisites

Phases 03 (routes registered), 05/06/07 (real handlers, not stubs), 09 (stats routes — can be done in parallel; spec just covers them later).

### 8.3 Queued PDF generation

Install Browsershot + Chromium in the PHP image. Update `docker/php/Dockerfile`:

```dockerfile
RUN apk add --no-cache chromium nss freetype harfbuzz ca-certificates ttf-freefont
ENV PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true
ENV PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium-browser
```

`app/Jobs/GenerateApiDocsPdfJob.php`:

```php
final class GenerateApiDocsPdfJob implements ShouldQueue
{
    use Queueable;

    public int $tries = 3;
    public int $timeout = 90;

    public function __construct(
        public readonly string $exportId,
        public readonly string $locale,
    ) {}

    public function backoff(): array { return [30, 120, 300]; }

    public function handle(): void
    {
        $spec = Cache::get('openapi:spec:v1') ?? app(Generator::class)->__invoke();
        $html = view('pdf.api-docs', ['spec' => $spec, 'locale' => $this->locale])->render();

        $headerHtml = view('pdf.partials.header')->render();
        $footerHtml = view('pdf.partials.footer')->render();

        $path = storage_path("app/exports/{$this->exportId}.pdf");
        Browsershot::html($html)
            ->showBackground()
            ->format('A4')
            ->margins(20, 15, 20, 15)
            ->showBrowserHeaderAndFooter()
            ->headerHtml($headerHtml)
            ->footerHtml($footerHtml)
            ->setChromePath(env('PUPPETEER_EXECUTABLE_PATH'))
            ->save($path);

        Cache::put("export:pdf:{$this->exportId}", ['status' => 'ready', 'path' => $path], now()->addHour());
    }

    public function failed(\Throwable $e): void
    {
        Cache::put("export:pdf:{$this->exportId}", ['status' => 'failed', 'error' => $e->getMessage()], now()->addHour());
        Log::error('GenerateApiDocsPdfJob failed', ['exception' => $e, 'export_id' => $this->exportId]);
    }
}
```

### 8.4 Request + download endpoints

`RequestApiDocsPdfController`:

```php
public function __invoke(Request $request): JsonResponse
{
    $exportId = (string) Str::ulid();
    $locale = in_array($request->query('locale'), ['sk', 'en'], true) ? $request->query('locale') : app()->getLocale();
    Cache::put("export:pdf:{$exportId}", ['status' => 'queued'], now()->addHour());
    GenerateApiDocsPdfJob::dispatch($exportId, $locale);
    return response()->json(['export_id' => $exportId, 'status' => 'queued'], 202);
}
```

`DownloadApiDocsPdfController`:

```php
public function __invoke(string $exportId): Response
{
    $state = Cache::get("export:pdf:{$exportId}");
    if ($state === null) abort(404);
    if ($state['status'] === 'queued' || $state['status'] === 'processing') {
        return response()->json($state, 202);
    }
    if ($state['status'] === 'failed') {
        return response()->json($state, 500);
    }
    return response()->download($state['path'], 'webte2-api-docs.pdf');
}
```

Frontend polls `/api/v1/api-docs/pdf/{id}` every 1 s up to 30 s, shows a spinner.

### 8.5 Daily regeneration

`RegenerateApiDocsCacheJob`:

```php
final class RegenerateApiDocsCacheJob implements ShouldQueue, ShouldBeUnique
{
    public int $uniqueFor = 3600;
    public function uniqueId(): string { return 'regen-api-docs'; }

    public function handle(Generator $generator): void
    {
        $spec = $generator();
        Cache::put('openapi:spec:v1', $spec, now()->addDays(2));
        Log::info('OpenAPI spec cache regenerated', ['paths' => count($spec['paths'] ?? [])]);
    }
}
```

`routes/console.php`:

```php
Schedule::job(new RegenerateApiDocsCacheJob)->dailyAt('04:00');
```

## Risks

| Risk | Mitigation |
|---|---|
| Chromium memory in cli container | Memory limit + Browsershot timeout; restart on OOM |
| Cold-start Chromium (~2 s) | Acceptable; the queue absorbs latency |
| Spec drift vs implementation | Scramble derives from code; `RegenerateApiDocsCacheJob` daily catches drift |
